## 模组介绍
象牙怨灵相关的恋爱拓展，更新至v1.3.0，包含以下内容：
1. 偷项链并归还
2. 幽灵成为可恋爱对象（包含社交栏文本拆分，专属特质，同心吊坠，遭遇战对话等）
3. 海螺聊天
4. 新增和修改了几个幽灵事件
5. 幽灵事件概率增加
6. 还项链后可选择性进分裂剧情（依旧需要高创伤）
7. 湖边约会

没有动的内容：苍白后代相关，遭遇战
## 准备工作
- 游戏本体0.5.11+（旧版本必爆红，但也能玩到大部分内容）
- Modloader模组加载器
- （已在v1.2优化，此条内容删除，但仅限0.5.10+版本才能生效）
## 剧情开启要求
看过分裂，并且知道项链去向（博物馆询问或者进市长办公室），能够触发米奇的名声任务。去酒吧通过兰德里找米奇，偷到项链后等血月被附身到湖底

海螺要在湖底摸罐子（以还项链为前提）

米奇任务和原版一个事件共用了页面，会触发一个本来难度偏高的原版金色成就
## 模组适配
- dc上的幽灵恋爱Wraith Additions：不适配，爆红一堆，但严重bug也不多。我用的是英文最新版，吧里的优化版在我这爆红更厉害

两个mod会导致社交栏同时出现两个幽灵。幽灵的好感上限锁和随机事件概率取决于你把哪个mod放在前面加载（这方面推荐先加载我的），大部分爆红还是因为汉化问题。

目前就发现这些冲突，不介意的话可以一起用，湖边上供什么的可以正常触发
- 和其他mod的适配：我用的秋枫框架，鹰宝宝和一些美化，大型mod都没有，如果有报错的话尽快跟我反馈一下，尽量改
